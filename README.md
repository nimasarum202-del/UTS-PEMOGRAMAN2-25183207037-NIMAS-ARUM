## Deskripsi
Program ini merupakan aplikasi sederhana berbasis Java
untuk mengelola penyewaan kendaraan mobil dan motor.

## Fitur
1. Tambah Kendaraan
2. Tampilkan Kendaraan
3. Ubah Data
4. Hitung Biaya Sewa
5. Detail Kendaraan
